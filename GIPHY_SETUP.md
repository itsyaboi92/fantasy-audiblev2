GIPHY GIF picker (v9)

1. Create a Web API key at https://developers.giphy.com/dashboard/
2. Add GIPHY_API_KEY in Render Environment; remove TENOR_API_KEY if desired.
3. Deploy server.js, public/app.js, public/index.html.
4. GIPHY beta keys are limited to 100 API calls/hour. Searches run directly in the browser per GIPHY documentation.
5. No GIF files are uploaded or stored; only GIPHY media URLs are saved in chat.
6. GIFs must display Powered by GIPHY attribution.
